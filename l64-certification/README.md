# l64-certification

`l64-certification` is the current native structural-certification carrier.

It certifies only facts already carried by canonical native authority:

- an `L64D` frame decodes and re-encodes exactly;
- every native context yields a certification projection that verifies against that authority;
- each burden is directly classified as discharged, open, invalid, or missing evidence;
- an `L64B` frame is valid ordered transport whose members are certified independently.

It does not create theorem registries, campaign records, cache keys, receipts, policy graphs, merged bundle worlds, or composite bundle authority. A compact state symbol is reported for diagnostics only; positive authority remains exact canonical DNA.
