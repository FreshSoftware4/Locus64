# Semantic Usage Guide

- Treat canonical `L64R1`/`L64D` bytes as authority.
- Treat `L64B` as ordered transport only.
- Treat projections, certification, observation, and change as verified non-authoritative views.
- Do not recreate registry, campaign, research-host, tower, policy, cache, planning, or receipt schemas.
- Historical archives are forensic evidence, not runtime inputs.
